## 4. Game points

Each eligible game publishes fixed score thresholds worth 0, 5, 10, or 20 championship points. A score between thresholds receives the points for the highest threshold reached. Each player receives two official attempts per game per day. Starting an attempt consumes it; leaving, reloading, or letting it expire does not restore it. Practice and guest scores do not count.

Existing deterministic ranking factors are total points, the best period total, and the time the final total was reached.
