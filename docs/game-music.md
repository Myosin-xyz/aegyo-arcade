# Game Music Intake

**Status:** implemented for internal catalog testing (2026-08-03); four
per-game loops added from Dai Dai's second delivery (2026-09-21).

**Raw source:** gitignored `music_aegyo_game/` delivery.
**Runtime:** twelve lazy, looping catalog MP3s under
`public/games/music/`; generated by `scripts/export-game-music.sh`.

The raw files contain no ID3 title, artist, copyright, or license fields.
Myosin must retain the contributor/source record alongside the shared
archive before public release. The export strips metadata and normalizes
all tracks to -20 LUFS / -2 dBTP at 112kbps. Music does not load from the
landing page; it attaches only when a game run starts.

Music is host presentation, not a frozen runtime-contract addition. It
follows the existing mute, pause/resume, end, restart, and destroy states.
Synthesized game SFX remain on `AudioBus` v1.

Every game with file music now has its own track. Until 2026-09-21 Photocard
Stack and Aegyo Pop shared `freebie.mp3`, Bias Match shared `hangman.mp3`, and
Perfect Toss shipped silent. Fanchant Hero keeps its authored beat/melody
instead of layering an unrelated loop, so it still has no `musicTrack`.

## Second delivery: cut to loops (2026-09-21)

The first delivery was 30-second clips. The second is seven full songs of
three to four minutes at 192kbps, about 4.2 MB each. Shipped whole at the
catalog's 112kbps they would cost about 2.5 MB per game, against a 300 KB
per-game art budget on a mid-range Android floor device. Each shipped track is
cut to one bar-aligned loop the size of the originals.

| Game            | Runtime file          | Source song         | Loop                      | Size   |
| --------------- | --------------------- | ------------------- | ------------------------- | ------ |
| Perfect Toss    | `perfect-toss.mp3`    | Pixel Hearts        | 28.8 s, 12 bars @ 100 BPM | 394 KB |
| Aegyo Pop       | `aegyo-pop.mp3`       | Pixel Heist         | 30.0 s, 16 bars @ 128 BPM | 411 KB |
| Photocard Stack | `photocard-stack.mp3` | Pixel Quest Horizon | 29.5 s, 16 bars @ 130 BPM | 404 KB |
| Bias Match      | `bias-match.mp3`      | Pixel Puzzle Peace  | 33.9 s, 12 bars @ 85 BPM  | 464 KB |

The seven songs are four styles: Hearts and Starlight Pixels share one prompt,
Heist and Pixel Burglar another, Puzzle Peace and Lofi Pixel Rest a third, and
Quest Horizon stands alone. One style went to each game. Starlight Pixels,
Pixel Burglar, and Lofi Pixel Rest stay in the archive as alternates.

Loop points come from a similarity search over the song: for a span of about
30 seconds, the audio that follows the end has to match the audio that follows
the start, so the restart continues the phrase. All four landed on whole
phrases without being told the tempo. Starlight Pixels was passed over because
its only clean phrase-length loops either run through a quiet breakdown or
last 19 seconds. After each restart the audio is 0.97 to 0.99 similar to what
the song itself played next, against 0.68 to 0.86 for random positions.

`encode_loop` applies one constant gain toward -20 LUFS, capped at -2 dBTP,
where `encode` uses dynamic loudnorm. A gain that moves over time can leave
the two sides of a seam at different levels. The four loops measure -20.4 to
-20.5 LUFS. An `<audio loop>` MP3 still restarts with the codec's few
milliseconds of padding, the same as the original eight.
